# 学習データ（コンテンツの正本とテンプレート）

県立中 確認テストの収録内容を管理する場所です。
**スプレッドシート → CSV → アプリ** という流れで、CSV（`*_source.csv`）が「正本（元データ）」です。

> 現在入っているのは**動作確認用のサンプル問題（各科目5問）**です。
> 実データ（CSV／スプレッドシート）を受け取り次第、`rika_source.csv` / `shakai_source.csv` を上書きしてください。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `rika_source.csv` | **理科の正本**。ここを編集すると `js/rika.js` に反映されます。 |
| `shakai_source.csv` | **社会の正本**。ここを編集すると `js/shakai.js` に反映されます。 |

> アプリ画面からも現在のデータを書き出せます（バックアップ／確認用）。
> 各科目の設定画面の「**収録問題をCSVで書き出す**」ボタンから、その時点の最新データがダウンロードされます。

## CSVの形式（5列）

理科・社会とも、問題は「問題文 → 答え」の一問一答です。形式は共通の5列です。

| 列 | 内容 | 例 |
| --- | --- | --- |
| `単元` | **教科の中の単元**（章）。アプリの「単元」チップに並びます | `身近な物理現象` / `世界と日本の姿` |
| `項目` | **単元の中の項目**（節）。アプリの「項目」チップに並びます | `光の性質` / `地球の姿` |
| `問題` | 問題文 | `光が物体の表面ではね返る現象を何というか。` |
| `答え` | 正解 | `反射` |
| `誤答候補` | （任意）その問題で出したい**間違いやすい選択肢**。`;`（セミコロン）で区切る | `屈折;分散;全反射;乱反射` |

- 文字コードは **UTF-8（BOM付き）**。Excel でそのまま開けます。
- 値にカンマ `,` や `"` が含まれてもよいように、各セルは `"` で囲んでいます。
- **同じ「単元＋項目」が1つのまとまり**になります。並べた順に出題候補へ入ります。
- 1つの項目は **4問以上**あると4択がきれいに作れます（少なくても動きますが選択肢が減ります）。
  8択を使うなら8問以上が目安です。

## 誤答（ダミー）選択肢の仕組み

4択・8択の誤答は次の優先順で自動的に組み立てられます（study-tool と同じ）。

1. **`誤答候補` 列に書いた候補**（その問題専用。ここから優先してランダムに選ばれます）
2. 足りない分は **同じ項目の他の答え**
3. それでも足りなければ **同じ単元 → 全体の答え**

つまり「この問題ではこれを引っかけに出したい」という語を `誤答候補` に並べておけば、
毎回その中からランダムに混ざります。空欄なら同項目の用語から自動生成されます。

## スプレッドシートとの連携・自動反映

1. スプレッドシートで内容を編集する。
2. 「ファイル → ダウンロード → カンマ区切り（.csv）」で書き出す。
3. 書き出したCSVを、このフォルダの **`rika_source.csv` / `shakai_source.csv` に上書き**してコミット
   （GitHubのWeb上で「Upload files」でも可）。
4. **GitHub Actions が自動で `js/rika.js`・`js/shakai.js` を生成し直し**、コミットします（数十秒）。
5. 反映後、アプリをハード再読み込みすると最新の内容で出題されます。

> 手元で反映を確認したいときは、`kenritsu-tool/` で `node tools/build-data.js` を実行すると同じ生成が走ります。
> 単元ID・項目IDは**ラベル（単元名・項目名）が同じなら引き継がれる**ので、学習記録（ベストスコア）も維持されます。

## 科目を増やすとき

1. `js/<科目>.js` を `rika.js` を雛形にコピー（global 名・`mode`・`groupId`・ラベルを変更）。
2. `tools/build-data.js` の `CONFIGS` に1ブロック追加（`name`/`csv`/`file`/`globalName`）。
3. `index.html` にメニューカードと設定セクションを追加、`js/app.js` の `init()` に配線を追加。
4. `.github/workflows/build-data.yml` の `paths` と実行・コミット対象に新 source CSV / js を追加。

## 注意

- `js/rika.js`・`js/shakai.js` のデータ部分（`AUTO-GENERATED` のブロック）は
  **CSVから自動生成**されます。直接編集せず、`*_source.csv` を編集してください。
- 反映は GitHub Actions（自動）または `node tools/build-data.js`（手動）で行います。
- 学習記録は各端末のブラウザ内（localStorage）に保存されます。保存キーは
  `chishokan-kenritsu:*` で、study-tool（`chishokan-study-tool:*`）とは分離されています。
