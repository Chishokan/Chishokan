# 面談予約システム（智翔館版・中等部）

学習塾「智翔館」中等部の保護者向け **面談予約Webアプリ**。
**Google Apps Script (GAS) + Googleスプレッドシート + HTML** で構築されている本番運用中のシステムを、
clasp を使って Git 管理できるようにしたものです。

> ⚠️ **本番運用中のシステムです。** 実際に保護者が予約に使っています。破壊的変更は厳禁です。
> 本番GASへの反映（`clasp push` ＋ 再デプロイ）は、**変更内容をオーナーが確認・承認してから**行ってください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `コード.js` | サーバー側ロジック（GAS本体）。データ取得・予約処理・通知・リマインド等すべて。※GAS上では `コード.gs` |

## データ構造（スプレッドシート）

校舎ごとに2シートずつ存在する（シート名は校舎名から動的生成）。

### 予約枠シート（〇〇予約枠）

| 列 | 内容 |
| --- | --- |
| A | 日付 |
| B | 時刻 |
| C | 枠ラベル（任意・画面上は非表示） |
| D | 公開（TRUE/FALSE） |
| E | 定員（既定1、1〜2想定） |

### 予約データシート（〇〇予約データ）

| 列 | 内容 |
| --- | --- |
| A | 予約ID |
| B | 日付 |
| C | 時刻 |
| D | お子様名 |
| E | 保護者名 |
| F | メールアドレス |
| G | 学年 |
| H | 相談内容 |
| I | 状態（confirmed / cancelled） |
| J | 予約日時 |
| K | 職員メモ（保護者には非表示） |
| L | リマインド送信済（送信日時を記録、重複防止用） |

## 主な機能

- **保護者画面**：校舎選択 → 枠タップで予約フォーム → 確定。メールアドレスで予約一覧を横断検索。当日1時間前以降の枠は非表示。保護者からの変更・キャンセルは不可（電話案内）。
- **職員画面**：ログイン後、校舎セレクタ・予約一覧（フィルタ／名前検索／職員メモ／詳細モーダルで日時変更・キャンセル）・枠管理（期間指定の選択式追加、定員1↔2トグル、公開/非公開、削除、3モードの枠選択）。
- **定員機能**：定員1/2の切替。`getAvailableSlots` と `createBooking` で二重チェック。
- **リマインドメール**：翌日のconfirmed予約で未送信のものへ送信、L列に送信日時を記録して重複防止。トリガーは10:00と19:00の毎日（送信済みフラグで1人1通）。

> ℹ️ **新規予約通知について：** 旧版は智翔館版のみ LINE WORKS への新規予約通知を行っていましたが、
> 認証情報（秘密鍵等）をコードに含む必要があり公開リポジトリでの管理に適さないため、
> **本リポジトリ版では LINE WORKS 通知を廃止**しています（`createBooking` 内に TODO コメントを残しています）。
> 通知が必要になった場合は、RED版と同様のメール通知などで実装することを推奨します。

## 開発・反映フロー（clasp）

### 前提

- [clasp](https://github.com/google/clasp) をインストール：`npm install -g @google/clasp`
- Googleアカウントで認証：`clasp login`（ヘッドレス環境では `clasp login --no-localhost`）

### このプロジェクトを別環境にクローンする場合

```bash
clasp clone-script 1igsYiTslVES4Y36bv4BpBk5NAmK1uIHKMz39emov1kRaKNs9ADA7kyg5
```

### 本番GASへ反映する手順（★承認後のみ）

1. 変更差分をオーナーが確認・承認する。
2. `clasp push` でGASへ反映する。
3. GASエディタで **新バージョンとして再デプロイ**
   （デプロイ → デプロイを管理 → 鉛筆 → 新バージョン → デプロイ）。
   - **既存のデプロイURLを変えないため、必ず「新バージョン」で更新**すること。

## 安全のための鉄則

- 本番GASへの `clasp push` は、オーナーが変更内容を確認・承認してから。自律的に本番へ反映しない。
- **「初期化」関数を実行しない。** 予約枠シートのデータが消える。
- 再デプロイは必ず「**新バージョン**」。URLを変えると保護者の導線が切れる。
- **秘密情報（認証鍵・トークン等）をコミットしない。** `.clasprc.json` は `.gitignore` 済み。
- 変更前後で、保護者の予約フロー（枠選択→予約→完了）と職員の枠管理が壊れていないか確認する。
