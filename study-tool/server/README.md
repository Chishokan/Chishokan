# データ送信のセットアップ（得点 → スプレッドシート）

アプリの「学習記録 → **データを送信**」で、生徒の得点をスプレッドシートに集約できます。
静的サイト（GitHub Pages）から直接シートには書けないため、間に **Google Apps Script のウェブアプリ**を1つ用意します（無料・5分）。

## 手順

1. **記録用スプレッドシートを用意**（新規でOK。例：「智翔館 得点記録」）。
2. そのスプレッドシートで **拡張機能 → Apps Script** を開く。
3. `Code.gs`（このフォルダのもの）の中身を貼り付けて保存。
4. 右上 **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**：
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押し、表示される **ウェブアプリ URL（`https://script.google.com/macros/s/……/exec`）** をコピー。
5. リポジトリの **`study-tool/js/config.js`** を開き、`SHEET_ENDPOINT` にそのURLを貼り付けてコミット。
   ```js
   global.AppConfig = {
     SHEET_ENDPOINT: "https://script.google.com/macros/s/……/exec",
   };
   ```
6. アプリをハード再読み込み → 「学習記録 → データを送信」で 学年・校舎・名前 を選んで送信。
   スプレッドシートの **「得点データ」シート**に1テストにつき1行ずつ追記されます。

## 送られるデータ（1行ずつ）

| 列 | 内容 |
| --- | --- |
| 送信日時 | 送信した日時 |
| 学年 / 校舎 / 名前 | 送信フォームで入力した生徒情報 |
| テスト | テスト名（例「理科 / 中2 粒子（化学） / 4択」） |
| モード | calc / vocab / rika / shakai |
| ベスト得点・満点・正答率(%) | そのテストの自己ベスト |
| 受験回数 | そのテストの記録件数 |
| 直近得点・満点・直近受験日 | 最後に解いたときの結果 |

## 補足・注意

- 送信は端末内の学習記録（localStorage）が対象です。**端末ごと**に記録されるため、生徒の端末で送信してもらいます。
- 応答はクロスオリジンの制約で読めないため、アプリ側は「送信できたら成功表示」とする実装です（fire-and-forget）。シート側に行が増えているかで最終確認してください。
- URL を変更・再デプロイした場合は `config.js` の値も更新してください。
- 個人情報（氏名）を扱うため、スプレッドシートの共有範囲は塾内関係者のみに限定してください。
