# 単語データ（エクスポート / インポート）

英単語テストの収録単語を編集・追加するためのCSVを置く場所です。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `words_export.csv` | **現在アプリに入っている全単語**の書き出し（112語）。中身の確認・バックアップ用。 |
| `import_template.csv` | **新しい単語を追加するためのテンプレート**。これに記入して渡してください。 |

> アプリ画面からも書き出せます：英単語テストの設定画面 → 「**収録単語をCSVで書き出す**」。
> その時点の最新データがダウンロードされます（追加後の確認にも便利）。

## CSVの形式（4列）

| 列 | 内容 | 例 |
| --- | --- | --- |
| `学年` | 学年名 | `中1` / `中2` / `中3` |
| `範囲` | 出題範囲の名前（Unit / Part など） | `Unit2 Part1` / `Unit1 Talent Show R&T・T&S` |
| `英語` | 英単語・連語 | `reach` / `take part in ~` |
| `日本語` | 意味 | `（目標に）手が届く` |

- 文字コードは **UTF-8（BOM付き）**。Excel でそのまま開けます。
- 値にカンマ `,` や `"` が含まれてもよいように、各セルは `"` で囲んでいます。
  Excel で編集して上書き保存すれば自動で同じ形式になります。
- **同じ「学年＋範囲」が1つのまとまり**になります。並べた順に出題候補へ入ります。
- 「`〜`」「`?`」などの記号や全角・半角はそのまま登録されます（記述問題の採点では記号・空白は無視されます）。

## 新しい単語を追加する手順

1. `import_template.csv`（または `words_export.csv`）を Excel で開く。
2. 行を追加して `学年 / 範囲 / 英語 / 日本語` を記入する。
   - 既存の範囲に足す → その範囲名（例 `中2 / Unit1 Talent Show Part1`）をそのまま書く。
   - 新しい学年・Unitを作る → 新しい名前（例 `中3 / Unit1 Part1`）を書くだけ。
3. CSV（UTF-8）で保存し、このフォルダに置く or 渡す。
4. 取り込み（`js/vocab.js` への反映）を行うと、アプリの「学年 → 出題範囲」に自動で現れます。

> 1つの範囲は **4語以上**あると4択がきれいに作れます（少なくても動きますが選択肢が減ります）。

## 注意

- `words_export.csv` は自動生成物です。手で編集しても**アプリには反映されません**
  （アプリの単語は `js/vocab.js` が正本）。追加は上の手順で取り込みます。
