# 学習データ（エクスポート / インポート）

英単語テスト・理科テストの収録内容を編集・追加するためのCSVを置く場所です。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `words_export.csv` | **現在アプリに入っている全単語**の書き出し（234語）。中身の確認・バックアップ用。 |
| `import_template.csv` | **新しい単語を追加するためのテンプレート**。これに記入して渡してください。 |
| `rika_export.csv` | **現在アプリに入っている全理科問題**の書き出し（380問）。中身の確認・バックアップ用。 |
| `rika_import_template.csv` | **新しい理科問題を追加するためのテンプレート**。これに記入して渡してください。 |

> アプリ画面からも書き出せます：英単語テストの設定画面 → 「**収録単語をCSVで書き出す**」。
> その時点の最新データがダウンロードされます（追加後の確認にも便利）。

## CSVの形式（4列）

| 列 | 内容 | 例 |
| --- | --- | --- |
| `学年` | 学年名 | `中1` / `中2` / `中3` |
| `範囲` | 出題範囲の名前（Unit / Part など） | `Unit2 Part1` / `Unit1 Talent Show R&T・T&S` |
| `英語` | 英単語・連語 | `reach` / `take part in ~` |
| `日本語` | 意味 | `（目標に）手が届く` |

- 文字コードは **UTF-8（BOM付き）**。Excel でそのまま開けます。
- 値にカンマ `,` や `"` が含まれてもよいように、各セルは `"` で囲んでいます。
  Excel で編集して上書き保存すれば自動で同じ形式になります。
- **同じ「学年＋範囲」が1つのまとまり**になります。並べた順に出題候補へ入ります。
- 「`〜`」「`?`」などの記号や全角・半角はそのまま登録されます（記述問題の採点では記号・空白は無視されます）。

## 新しい単語を追加する手順

1. `import_template.csv`（または `words_export.csv`）を Excel で開く。
2. 行を追加して `学年 / 範囲 / 英語 / 日本語` を記入する。
   - 既存の範囲に足す → その範囲名（例 `中2 / Unit1 Talent Show Part1`）をそのまま書く。
   - 新しい学年・Unitを作る → 新しい名前（例 `中3 / Unit1 Part1`）を書くだけ。
3. CSV（UTF-8）で保存し、このフォルダに置く or 渡す。
4. 取り込み（`js/vocab.js` への反映）を行うと、アプリの「学年 → 出題範囲」に自動で現れます。

> 1つの範囲は **4語以上**あると4択がきれいに作れます（少なくても動きますが選択肢が減ります）。

## 注意

- `words_export.csv` は自動生成物です。手で編集しても**アプリには反映されません**
  （アプリの単語は `js/vocab.js` が正本）。追加は上の手順で取り込みます。

# 理科テストのデータ

理科テストは「問題文 → 答え」の一問一答です。学年（中1/中2/中3）× 分野
（生命（生物）／粒子（化学）／地学（地球）／エネルギー（物理））で出題範囲が決まります。

> アプリ画面からも書き出せます：理科テストの設定画面 → 「**収録問題をCSVで書き出す**」。

## CSVの形式（5列）

| 列 | 内容 | 例 |
| --- | --- | --- |
| `学年` | 学年名 | `中1` / `中2` / `中3` |
| `範囲` | 分野名 | `生命（生物）` / `粒子（化学）` / `地学（地球）` / `エネルギー（物理）` |
| `問題` | 問題文 | `花のつくりで、めしべの先端の部分を何というか。` |
| `答え` | 正解 | `柱頭` |
| `誤答候補` | （任意）その問題で出したい**間違いやすい選択肢**。`;`（セミコロン）で区切る | `酸素;窒素;二酸化炭素` |

## 誤答（ダミー）選択肢の仕組み

4択・8択の誤答は次の優先順で自動的に組み立てられます。

1. **`誤答候補` 列に書いた候補**（その問題専用。ここから優先してランダムに選ばれます）
2. 足りない分は **同じ分野の他の答え**
3. それでも足りなければ **同じ学年→全体の答え**

つまり「この問題ではこれを引っかけに出したい」という語を `誤答候補` に並べておけば、
毎回その中からランダムに混ざります。空欄なら同分野の用語から自動生成されます。

> ※ 現在取り込んでいるスプレッドシートには `誤答候補` は入っていないため、
> いまは同分野の答えから自動生成しています。引っかけを指定したい問題に追記してください。

## 注意

- `rika_export.csv` は自動生成物です。正本は `js/rika.js`。追加は CSV を渡して取り込みます。
