# 学習データ（コンテンツの正本とテンプレート）

英単語テスト・理科テストの収録内容を管理する場所です。
**スプレッドシート → CSV → アプリ** という流れで、CSV（`*_source.csv`）が「正本（元データ）」です。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `vocab_source.csv` | **英単語の正本**（234語）。ここを編集すると `js/vocab.js` に反映されます。 |
| `rika_source.csv` | **理科問題の正本**（380問）。ここを編集すると `js/rika.js` に反映されます。 |
| `shakai_source.csv` | **社会問題の正本**（地理50問）。ここを編集すると `js/shakai.js` に反映されます。 |
| `math_source.csv` | **数学問題の正本**（連立方程式120問）。ここを編集すると `js/math.js` に反映されます。 |
| `import_template.csv` | 英単語を追加するときの記入見本。 |
| `rika_import_template.csv` | 理科問題を追加するときの記入見本（誤答候補つき）。 |

> アプリ画面からも現在のデータを書き出せます（バックアップ／確認用）。
> 英単語・理科それぞれの設定画面の「**CSVで書き出す**」ボタンから、その時点の最新データがダウンロードされます。

## スプレッドシートとの連携・自動反映

スプレッドシートを「元データ」として運用できます。流れは次の通りです。

1. スプレッドシートで内容を編集する。
2. 「ファイル → ダウンロード → カンマ区切り（.csv）」で書き出す。
3. 書き出したCSVを、このフォルダの **`vocab_source.csv` / `rika_source.csv` に上書き**してコミット（GitHubのWeb上で「Upload files」でも可）。
4. **GitHub Actions が自動で `js/vocab.js`・`js/rika.js` を生成し直し**、コミットします（数十秒）。
5. 反映後、アプリをハード再読み込みすると最新の内容で出題されます。

> 手元で反映を確認したいときは、`study-tool/` で `node tools/build-data.js` を実行すると同じ生成が走ります。
> 学年ID・範囲IDは**ラベル（学年名・範囲名）が同じなら引き継がれる**ので、学習記録（ベストスコア）も維持されます。

# 英単語データ（`vocab_source.csv`）

## CSVの形式（4列）

| 列 | 内容 | 例 |
| --- | --- | --- |
| `学年` | 学年名 | `中1` / `中2` / `中3` |
| `範囲` | 出題範囲の名前（Unit / Part など） | `Unit2 Part1` / `Unit1 Talent Show R&T・T&S` |
| `英語` | 英単語・連語 | `reach` / `take part in ~` |
| `日本語` | 意味 | `（目標に）手が届く` |

- 文字コードは **UTF-8（BOM付き）**。Excel でそのまま開けます。
- 値にカンマ `,` や `"` が含まれてもよいように、各セルは `"` で囲んでいます。
- **同じ「学年＋範囲」が1つのまとまり**になります。並べた順に出題候補へ入ります。
- 「`〜`」「`?`」などの記号や全角・半角はそのまま登録されます（記述問題の採点では記号・空白は無視されます）。
- 1つの範囲は **4語以上**あると4択がきれいに作れます（少なくても動きますが選択肢が減ります）。

# 理科データ（`rika_source.csv`）

理科テストは「問題文 → 答え」の一問一答です。学年（中1/中2/中3）× 分野
（生命（生物）／粒子（化学）／地学（地球）／エネルギー（物理））で出題範囲が決まります。

## CSVの形式（5列）

| 列 | 内容 | 例 |
| --- | --- | --- |
| `学年` | 学年名 | `中1` / `中2` / `中3` |
| `範囲` | 分野名 | `生命（生物）` / `粒子（化学）` / `地学（地球）` / `エネルギー（物理）` |
| `問題` | 問題文 | `花のつくりで、めしべの先端の部分を何というか。` |
| `答え` | 正解 | `柱頭` |
| `誤答候補` | （任意）その問題で出したい**間違いやすい選択肢**。`;`（セミコロン）で区切る | `酸素;窒素;二酸化炭素` |

> 分野名（`範囲`）は上の4種類が決まった表示順を持っています。新しい分野を増やすときは
> コード側（`js/rika.js` の `STRAND_ORDER`）の追記も必要なので、その場合は声をかけてください。

## 誤答（ダミー）選択肢の仕組み

4択・8択の誤答は次の優先順で自動的に組み立てられます。

1. **`誤答候補` 列に書いた候補**（その問題専用。ここから優先してランダムに選ばれます）
2. 足りない分は **同じ分野の他の答え**
3. それでも足りなければ **同じ学年→全体の答え**

つまり「この問題ではこれを引っかけに出したい」という語を `誤答候補` に並べておけば、
毎回その中からランダムに混ざります。空欄なら同分野の用語から自動生成されます。

# 社会データ（`shakai_source.csv`）

社会も「問題文 → 答え」の一問一答です。理科と同じ5列の形式で、誤答候補の仕組みも同じです。
ただし上位の区分の意味だけが異なります。

| 列 | 内容 | 例 |
| --- | --- | --- |
| `学年` | **単元**（章）として使います | `地理１ 世界と日本の姿` / `地理２ 人々の生活と環境` |
| `範囲` | **項目**（節） | `地球の姿` / `日本の姿` / `世界の気候` |
| `問題` | 問題文 | `面積が世界最大の大陸を何というか。` |
| `答え` | 正解 | `ユーラシア大陸` |
| `誤答候補` | （任意）間違いやすい選択肢。`;` 区切り | `アフリカ大陸;北アメリカ大陸;南アメリカ大陸;オーストラリア大陸` |

- アプリの「単元」チップに `学年` 列が、「項目」チップに `範囲` 列が並びます。
- 歴史・公民を増やすときは、`学年` に `歴史１ …` などの単元名を入れて行を足すだけで、新しい単元として現れます。

# 数学データ（`math_source.csv`）

数学も理科・社会と同じ5列の形式です。連立方程式は「問題（連立式）→ 答え（x, y の組）」で、4択で出題します。

| 列 | 内容 | 例 |
| --- | --- | --- |
| `学年` | **単元** | `連立方程式` |
| `範囲` | **種類**（解法タイプ） | `代入法` / `加減法` / `かっこを含む式` / `小数をふくむ式` / `分数をふくむ式` / `A＝B＝C の形` |
| `問題` | 連立式（2式を `, ` で区切る／分数は `x/6` など） | `x = 3y - 7, -2x - y = -14` |
| `答え` | 解の組 | `x=5, y=4` |
| `誤答候補` | 間違いやすい解の組。`;` 区切り | `x=-5, y=4;x=5, y=-4;x=-5, y=-4;x=4, y=5` |

- 問題は `tools/` の生成スクリプトで作った類似問題（種類ごと約20問）です。手で問題を足す・直すときは、答えの組と誤答候補も合わせて編集してください。
- 答え・誤答は `x=（値）, y=（値）` の形式に揃えると選択肢がきれいに並びます。

## 注意

- `js/vocab.js`・`js/rika.js`・`js/shakai.js`・`js/math.js` のデータ部分（`AUTO-GENERATED` のブロック）は
  **CSVから自動生成**されます。直接編集せず、`*_source.csv` を編集してください。
- 反映は GitHub Actions（自動）または `node tools/build-data.js`（手動）で行います。

# 学習記録の送信（得点管理）

学習記録（ベストスコア・履歴）は各端末のブラウザ内（localStorage）に保存されます。
「学習記録」画面の **「データを送信」** から、学年・校舎・名前を選んで先生のスプレッドシートへ得点を送れます。

- 送信先（Google Apps Script の URL）の設定方法は **`server/README.md`** を参照。
- 送信先URLは **`js/config.js` の `SHEET_ENDPOINT`** に貼り付けます。
- 1テストにつき1行（生徒情報＋ベスト得点・受験回数・直近得点など）がシートに追記されます。
