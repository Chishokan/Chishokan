# 智翔館 学習ドリル

学習塾「智翔館」中等部の生徒向けの **学習・演習ツール**。
ビルド不要の **静的 HTML / CSS / JavaScript** だけで動きます（サーバー・ログイン不要）。

> このアプリは、本番運用中の面談予約システム（`interview-booking/`）とは
> **完全に独立**しています。互いに影響しません。

## 機能

- **計算ドリル** … たし算 / ひき算 / かけ算 / わり算 / ミックスを自動生成。
  レベル（やさしい・ふつう・むずかしい）と問題数（5・10・20）を選べます。
  わり算は必ず割り切れる問題のみ出題。タイマー付き。
- **英単語テスト** … 内蔵単語を **学年 → 出題範囲（Unit/Part）** の2段階で選んで出題。
  方向（英語→意味 / 意味→英語）と、出題形式 **4択 / 8択 / 記述（つづり入力）** を選べます。
  各学年に「全範囲」もあります。
- **マイ単語帳** … 英単語で間違えた単語を自動でためる単語帳。**正解できると自動で消えます**。
  たまった単語だけを 4択 / 8択 / 記述で復習できます（個別削除・全消去も可）。
- **学習記録** … 各モードのベストスコアと直近の履歴を保存・表示。
  記録・マイ単語帳は `localStorage` でこの端末（ブラウザ）にのみ保存されます。

## 使い方

ローカルで開くだけで動きます。

```bash
# いちばん簡単：ブラウザでファイルを直接開く
open study-tool/index.html        # macOS
# または study-tool/index.html をダブルクリック

# 簡易サーバーで開く場合（任意）
cd study-tool
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

GitHub Pages 等の静的ホスティングにそのまま載せられます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面のマークアップ（メニュー・設定・出題・結果・記録） |
| `css/style.css` | スタイル一式 |
| `js/storage.js` | 学習記録の保存・読み出し（localStorage） |
| `js/calc.js` | 計算ドリルの問題生成 |
| `js/vocab.js` | 英単語データ（学年→範囲）と問題生成。正本データはここ |
| `js/app.js` | 画面遷移・出題フロー・マイ単語帳・CSV書き出しの制御 |
| `data/` | 単語のエクスポート/インポート用CSVと説明（`data/README.md`） |

## 単語を追加・変更するには

正本データは `js/vocab.js` の `GRADES`（学年 → `sets`（範囲）→ `words`）です。
`{ en: "英語", ja: "意味" }` を追加するだけで、画面の「学年／出題範囲」に自動反映されます。

CSVでまとめて編集したい場合は **`data/` フォルダ**を参照してください。

- `data/words_export.csv` … 現在の全収録単語の書き出し（確認・バックアップ用）
- `data/import_template.csv` … 新規追加用テンプレート（`学年, 範囲, 英語, 日本語`）

アプリ画面（英単語テストの設定）からも「**収録単語をCSVで書き出す**」で最新データを出力できます。

## 動作環境

モダンブラウザ（Chrome / Safari / Edge / Firefox の最近のバージョン）。
外部ライブラリ・ネットワーク通信は使用していません。
